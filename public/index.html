NES

Game Genie

Use standard 6 or 8 letter NES Game Genie codes, or ROM codes such as 8000:FF or 8000:FF?01. Codes must match your ROM version. Some startup codes need Start fresh. Changes apply without resetting your game. Switching a code off stops future patched ROM reads; effects already in game memory may remain until Start fresh.

Codes are saved separately for this viewer and game on this browser. Import replaces this game's list. Export contains only the code list. For overlapping codes, the first matching enabled code wins.

Keyboard, controllers & saves

Player 1: arrows, X = A, Z = B, Enter = Start, Shift = Select. Player 2: I/J/K/L = directions, N = A, M = B, 8 = Start, 7 = Select. Connect up to two standard controllers. Touch controls use player 1.

Automatic saves resume each viewer's game on this browser. Save and Load save use a separate manual slot. Rotate your device for a landscape layout. Games pause when you leave the tab or app.

For Duck Hunt, select it in the combined cartridge menu, turn on Light gun, then click or tap the game screen to aim and shoot.

Settings

Interface

Simple keeps the normal experience to posters, episodes, Play, My list, resume, and automatic recovery. Full reveals source controls, per-title tuning, playback health, and technical feedback.

Parental controls

Kid Mode is stored on this device for this viewer. It survives reloads and browser restarts. Leaving a restricted viewer, opening Settings, or signing out requires the Parent PIN.

No allowance limits

An episode counts after 5 actual watched minutes or 20% of its runtime, whichever comes first. A movie counts after 10 actual watched minutes. Once an episode or movie counts, that same item can still be finished or resumed. A time allowance stops immediately when its minutes run out. Enter 0 to leave any limit unlimited.

Playback

Pauses playback and asks “Still watching?” after the selected viewing period. The clock carries across auto-next episodes, so a short show cannot run all night by continually restarting it.

Episodes and history

Up Next appears during the credits. Play next now skips immediately. Watch credits cancels the early countdown but still advances when the episode actually ends.

Watch party

Watch the same exact file together using the host’s TorBox connection. Your invited viewer needs no account or API key. Either viewer can play, pause or seek. Playback runs at 1× and waits if a viewer buffers or disconnects.

Guests use your TorBox connection. TorBox playback links can include your full API key, which can give an invited viewer access to your TorBox account. Invite only someone you trust with that access. Ending the party does not revoke a copied key; reset it in TorBox to revoke that access.

Send this private invitation to one other viewer. It expires after six hours.

Changing videos or leaving the player ends your participation. Auto-next and automatic source switching pause while a party is active.
