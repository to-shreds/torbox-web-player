# Sports expansion, 2026-10-11

Web release 1.2.2 and independent native APK 0.2.3 expand the original four live channels and sixteen padel replays.

| Catalog | Web | Native APK |
| --- | ---: | ---: |
| Live channels | 36 | 39 |
| Live stream choices | 48 | 51 |
| Dated full replays | 157 | 157 |
| Sport filters | 25 | 26 |

New live channels include NFL classics/coverage, MLB, NBA classics, NASCAR, NHRA, Formula 1 classics, beIN SPORTS XTRA in English/Spanish, PGA TOUR, GolfPass, RugbyPass TV, Willow Sports, FloHockey, FloRacing, PFL, UFC classics, Billiard TV, FUEL TV and additional tennis offerings. Android also has fubo Sports Network, SURFER TV and Pac-12 Insider, whose direct streams passed but browser CORS was missing. Archive/coverage channels are labelled accurately; they do not promise current premium league games.

The 141 added full event/session archives cover thirteen sports, including twelve American football games, hockey, tennis, cycling, surfing, motorsport, water/winter sports, soccer, skateboarding, athletics and climbing. The original sixteen replay IDs are retained for bookmarks. Every added replay has an exact official event date. Titles/dates/sports/providers are the only browsing metadata; descriptions, images, scores and results are discarded. The catalog is a bundled snapshot, not an automatic event guide.

Sports opens through `/#sports` without loading the private movie service, health check or login. A login-screen Sports shortcut also works without a TorBox key. The availability notice is removed. Existing adult/Kid Mode checks remain. Search and dynamic Sport/Channel filters handle the larger catalog; native TV results use forty-eight-card pages.

Sports media uses an isolated same-origin player document. Its exact HTTPS `connect-src` and `media-src` lists exclude Render, self, arbitrary hosts and wildcards. The HLS Fetch loader validates initial resource URLs and omits credentials. Approved CDN redirects are followed under this separate browser policy, which checks each redirect destination before network transport. This preserves legitimate CDN beacon redirects on T2, Pickleball TV, NHL, FUEL TV and Tennis Channel international. Red Bull JSON metadata still rejects redirects. Native HLS fallback has the same media policy and anonymous crossorigin mode. Native Android validates each media request and redirected HTTP request through its separate interceptor.

No relay, transcoding, playlist rewriting, media storage or new paid runtime service is added. Render retains metadata/authentication and header-only TorBox redirects. The existing 24-device fixture checks 288 playback starts and 576 seeks with zero upstream media fetches and zero application media-body bytes.

The original research checked anonymous API/master/variant/initial-segment paths for the additions, with production browser Origin and CORS. Thirty-two live subtitle paths and 237 declared manifest resources were audited. Geo-blocked, short and duplicate replay candidates were excluded. Real Chromium playback passed for NFL classics and the full English hockey replay; an initial football replay attempt reached the bounded timeout. These were individual checks, not a claim that every full recording was watched. Device/network availability can change.

Workspace maintenance removed the unpublished web patch and raw probe files. The already-built native APK and source were recovered byte for byte from uploaded Git objects; their checksums match. The dated catalog and exact hosts were restored from that preserved source. The existing web project was restored from main and the recorded patch, retaining the same planned 1.2.2 release. Native 0.2.3 was not rebuilt. Its archive contains actual build logs, test XML, signature/manifest evidence and the unchanged core-file comparison. Physical Firestick playback remains untested.
