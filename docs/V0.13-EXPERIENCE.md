# v0.13 Simple / Full Experience

## Scope

This release expands the browser-key clone while keeping the default interface deliberately simple. It implements requested ideas 1 through 11, 14, and 15. Requested ideas 12 and 13 are intentionally excluded.

## Implemented requested features

1. My list is separate from Recently Played and is stored per viewer in the browser.
2. Next Up derives the next released episode after the latest completed episode for each show.
3. Long-press poster shortcuts provide Play, My list, Details, and, in Full mode, Share.
4. Source memory records successful sources and gives a bonus to previously successful sources and release families.
5. Audio feedback can mark a source as known-good or no-sound on this device.
6. Bad source feedback locally blacklists a source from automatic selection until cleared.
7. Per-title quality overrides apply at the movie/show level.
8. Data saver, Balanced, and Prefer larger files profiles change automatic file-size preference.
9. When a later episode starts, earlier completed episodes from the same series can be removed from local history.
10. Simple mode is the default family-friendly mode. Full mode exposes advanced controls.
11. Full mode includes a playback-health panel and source feedback.
14. Search history is separate from Recently Played and supports individual deletion.
15. The frontend has a manifest, icon, install prompt integration, and static-shell service worker.

## Not implemented

12. No new prose source-comparison / "Recommended because..." explanation was added.
13. No quick replay-last-30-seconds feature was added.

## Simple mode

Simple mode hides source Options, Drive Share controls, per-title quality controls, playback-health controls, and other technical UI marked as advanced. Smart selection, resume, recovery, source learning, Next Up, My list, and other automation continue to operate underneath.

## Full mode

Full mode reveals the advanced controls. The current source can be marked Sound works, No sound, or Bad source. Per-title quality and source Options are visible. Drive Share is visible. Playback health provides state rather than exposing raw network errors.

## Local state and privacy

The following remain browser-local:

- My list.
- Recently Played / canonical resume.
- Search history.
- Simple / Full preference and other settings.
- Per-title quality.
- Source success and release-family memory.
- Audio feedback.
- Bad-source blocks.

No source-learning state is sent to public source providers. The direct media path remains TorBox CDN to browser.
