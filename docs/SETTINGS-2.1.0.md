# TorBox Player 2.1.0 settings redesign

Settings now opens on a small Basic settings tab intended for the normal Simple interface. It includes optional names for User 1 and User 2, whether to remember the last active user, interface mode, default quality, automatic next episode, resume rewind, and the Still Watching interval. Every Basic setting has an on-screen plain-English tooltip.

All other controls are organized under an Advanced label into separate Playback, Home & history, Discover & sources, Kids, and Devices & app tabs.

New advanced preferences include compact home poster spacing, explicit starting browse type/feed/genre, search responsiveness, and whether cached TorBox sources receive a strong ranking preference. Existing settings and behaviors remain present but are reorganized into the relevant tab.

User names are display labels only. Internal user identities remain viewer-1 and viewer-2, so existing Continue Watching, My List, searches, Kid Mode state, and progress are not migrated or re-keyed. Optional names are ordinary settings and therefore travel with backendless setup transfer. The selected active user remains device-local.
