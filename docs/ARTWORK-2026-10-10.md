# Artwork patch · 2026-10-10

Build: release-1.2.0-artwork.1. User-authorized frontend-only correction, independently maintained from TorBox TV.

The reported titles return legitimate JPEGs after redirecting from images.metahub.space to live.metahub.space. The website’s HTML image Content Security Policy rejected that exact destination. No API key, source-selection or video issue was involved.

The production image CSP now permits that exact HTTPS host. The common image binder validates expected hosts/HTTPS/credentials, attempts an exact-ID medium poster on failure, then makes one delayed cache-bypassed retry. It stops at three requests and abandons delayed work when a card has left the page. Missing URLs also use the same exact ID. Real images remain subject to third-party availability; no paid service or proxy was added. Script CSP remains self-only.

Public module versions and the scope-specific service-worker cache token are bumped together to update installed clients. No server source, Render mirror/configuration/service, playback behavior, history/settings format or authentication code was modified.

Local syntax checks passed. Node tests: 345 registered, 339 passed, zero failed, six optional checks skipped. Eight new artwork tests cover the exact live host/CSP, malicious destinations, missing URLs, deduplication, primary success without extra calls, size fallback, bounded retry, cancellation and recovery. All 15 browser tests passed, with zero failures. Browser tests exercise actual DOM/CSP with synthetic one-pixel images plus the existing synthetic-media regression suite. Live public probes verify real title image redirects and JPEG decoding separately; neither is authenticated TorBox playback.

A local full Chrome launch was blocked by unavailable Unix sockets. The official headless shell supports the existing test harness on this host. Playwright cannot intercept every URL of a redirect chain, so the positive CSP fixture targets the actual live destination; real HTTP probes validate the chain. Production functionality was not weakened to accommodate that harness limitation.
